# Desktop

Conake OS v0.1 uses XFCE as its lightweight desktop. Arc Dark, Papirus icons,
and the Whisker application menu provide a more polished starting point while
keeping the desktop replaceable independently of boot and memory profiling.

Use **Settings > Desktop** to choose among the default anime-inspired Sakura
wallpaper, the Moonlit wallpaper, and the original minimalist wallpaper. They
are installed under `/usr/share/backgrounds/conake/`.

The **Conake Store** launcher opens GNOME Software with Flatpak support. The
Flathub remote is registered during image creation; installing apps requires
an internet connection. Store apps are optional and do not start in the
background.
